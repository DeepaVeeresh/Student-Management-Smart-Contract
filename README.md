# Student-Management-Smart-Contract
CTA Activity - Student Management Smart Contract using Solidity, Remix IDE and Ganache

## About the Project
This project demonstrates a simple Student Management Smart Contract developed using Solidity. It allows users to store and retrieve student details on a blockchain.

## Technologies Used
- Solidity
- Remix IDE
- Ganache
- Ethereum Blockchain

## Smart Contract Functions

### 1. setDetails()
Stores the student's name and age in the smart contract.

### 2. getDetails()
Retrieves the stored student name and age.

### 3. studentName
Returns the stored student name.

### 4. studentAge
Returns the stored student age.

## Deployment Procedure
1. Write the Solidity smart contract in Remix IDE.
2. Compile the contract using Solidity Compiler.
3. Start a local Ethereum blockchain using Ganache.
4. Connect Remix IDE to Ganache using the RPC URL. ex: RPC:https://127.0.0.1:7545
5. Deploy the smart contract.
6. Execute transactions to store and retrieve student details.
